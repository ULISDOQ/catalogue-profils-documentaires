# Matchers ULISTAG

Méthodes réutilisables de comparaison de structures documentaires.

Un matcher n'est pas un profil documentaire et ne constitue pas, à lui seul, un ULISTAG qualifié.

## Candidats disponibles

- [anchor_graph](anchor_graph) — ancres textuelles et relations géométriques ; issu de GED-01.
- [visual_keypoints](visual_keypoints) — points visuels locaux, appariement Hamming et cohérence géométrique RANSAC ; introduit par GED-02 pour réutiliser le même mécanisme sur PDF texte et image-only.
