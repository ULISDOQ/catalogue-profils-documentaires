# ULISDOQ Catalogue

This surface contains documentary knowledge intended for reuse.

It is distinct from:
- `experiments/`: historical evidence, exploratory cases and research debt;
- `profile-builder/`: generic tooling;
- `ULISTAG/`: recognition implementations.

## Catalogue rule

Profiles are classified by documentary semantics, not by GED experiment number.

```text
catalogue/
  profiles/
    <domain>/
      <jurisdiction-or-context>/
        <family>/
          <profile-id>/
            <version>/
```

A profile may exist here as `CANDIDATE_UNQUALIFIED` without being available for automatic selection.

Promotion to an available catalogue profile requires qualification evidence distinct from profile construction.
